# Layout guidelines from the ICs' datasheets

What each part's maker says about placing it, with the source, and how the
board meets it. Rule 3.2 of
[ecad-standards/layout.md](https://github.com/calicopizzadelivery/ecad-standards/blob/main/layout.md):
best effort, written down; a row that is not met says why. Status is
*planned* until the board is routed, then *met* or *not met (reason)*.
